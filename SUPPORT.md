Thank you for using **ProjectName**.

If you need help, have questions, or encounter a problem, please use the following channels.

## Getting Help

- **Bug reports:** If you believe something is broken, open an issue in the repository and describe the problem.
- **Feature requests:** Share your ideas through GitHub Issues.
- **General questions:** Use GitHub Discussions if it is enabled for the project.
- **Documentation:** Check the project's README and documentation before opening a support request.

## Before Asking for Support

Please make sure to:

- Check existing issues and discussions.
- Use the latest available version of ProjectName.
- Provide enough information to reproduce your problem.
- Include relevant error messages, screenshots, or logs when appropriate.

## Reporting Issues

When reporting an issue, please include:

- A clear description of the problem.
- Steps to reproduce the issue.
- Expected behavior.
- Actual behavior.
- Relevant environment information, if applicable.

## Security Issues

Do not publicly disclose security vulnerabilities through GitHub Issues.

Please refer to [SECURITY.md](SECURITY.md) for instructions on reporting security-related concerns.

## Scope of Support

Support is provided on a best-effort basis. There is no guarantee of response times, fixes, or individual assistance.
