# Dari Community Starter

این ریپازیتوری یک قالب ابتدایی (Starter Template) برای پروژه‌های Dari Community است که با هدف ایجاد ساختار اولیه، یک‌سان و منظم برای پروژه‌های اوپن‌سورس ساخته شده است.

این قالب شامل فایل‌ها، راهنماها و قالب‌های عمومی است که می‌توانند در پروژه‌های مختلف استفاده شوند؛ از جمله قوانین مشارکت، امنیت، پشتیبانی، رفتار جامعه و قالب‌های گزارش‌دهی.

## استفاده

این ریپازیتوری به‌عنوان Template در نظر گرفته شده است. هنگام ایجاد یک پروژه جدید از این قالب، فایل‌ها و محتوای آن را متناسب با نیازهای پروژه خود تنظیم کنید.

به‌خصوص، فایل `README.md` را با توضیحات، هدف، نحوه استفاده و مستندات مربوط به پروژه جدید جایگزین کنید.

همچنین، در فایل‌هایی که نام `ProjectName` یا `اسم‌پروژه` استفاده شده است، نام واقعی پروژه خود را جایگزین کنید.

## فایل‌های موجود

- `LICENSE` — شرایط استفاده از پروژه.
- `CONTRIBUTING.md` — راهنمای مشارکت در پروژه.
- `CODE_OF_CONDUCT.md` — اصول رفتار در جامعه.
- `SECURITY.md` — راهنمای گزارش مشکلات امنیتی.
- `SUPPORT.md` — راهنمای دریافت پشتیبانی.
- `.gitignore` — جلوگیری از اضافه‌شدن فایل‌های غیرضروری.
- `.github/ISSUE_TEMPLATE/bug_report.yml` — قالب گزارش باگ.
- `.github/ISSUE_TEMPLATE/feature_request.yml` — قالب پیشنهاد قابلیت جدید.
- `.github/ISSUE_TEMPLATE/documentation.yml` — قالب درخواست یا گزارش مستندات.
- `.github/PULL_REQUEST_TEMPLATE.md` — قالب Pull Request.
